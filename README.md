# Chácaras à venda até 15 km de Itapetininga — out/2026

Site estático (HTML + CSS + JS puro) que lista 226 anúncios de chácaras, com filtros por preço, piscina, quartos, banheiros, distância, imobiliária e busca por texto.

- `index.html`, `styles.css`, `app.js`: o site. Os dados são carregados de `data.json`.
- `prep.py`: gera `data.json` a partir dos dados brutos coletados (ver `DATA_NOTES.md`).
- `DESIGN.md`: especificação de design.

Distâncias são estimativas em linha reta. Valores são exibidos como constam nos anúncios; "não informado" significa que o anúncio não traz o dado.
